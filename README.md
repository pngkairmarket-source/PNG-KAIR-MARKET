# PNG-KAIR-MARKET

A marketplace app for Papua New Guinea 🇵🇬

## About
PNG Kair Market helps people buy and sell products online across Papua New Guinea.

## Features
- Buy and sell products
- Local seller profiles
- Product categories
- Chat between buyers and sellers
- Easy mobile marketplace

## Goal
To create a simple digital market connecting PNG communities.
